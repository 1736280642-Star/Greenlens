# GreenLens Dashboard 产品功能需求 v2

> 状态：Approved for implementation
> 来源：2026-07-29 至 2026-08-03 用户需求、视觉反馈与桌面端范围决策
> 适用页面：`/dashboard`
> 验收优先级：Desktop only

## 版本升级备注（v2.2 → 多指标研究视图）

1. `EAS / EAA-ESI` 与“Yutong 的 EAA-ESI”是同一套主模型，不重复建设第二套卡片或入口。
2. “三方面构造指标”区域提供三个同位切换入口：`主分析`、`GSI`、`RED FLAG`。GSI 与 Red flag 都是稳健性检验，不新增独立页面。
3. GSI 通过公司代码与报告年度关联，在 Repository/API 边界聚合；原始 CSV 不进入前端包和代码仓库。重复公司年度优先保留总词数更多的记录，并暴露重复与质量标记。
4. 十年趋势跟随当前研究视图切换。主分析与 GSI 同时展示中位数和平均数，避免只看单一中位数掩盖分布变化；展开态补充四分位或样本量。
5. 用户可见术语统一为 `ESI` 与 `EAA-ESI`。`ESGSI`、`EAA_ESI` 等仅作为兼容源字段或内部契约代码保留。
6. Dashboard 顶层不展示 `metric-contract-v2` 等技术契约徽标；数据版本只在详情、导出或方法页按需呈现。

## 版本升级备注（v2.1 → CyberRisk Terminal v1.0 对齐）

依据 `GreenLens 风险总览 Dashboard 前端设计规格 v1.0`（Enterprise Cyber Risk Intelligence Terminal），对 v2 做以下覆盖式决议，与 v2 不一致时以本节为准：

1. **主题色统一为黑青 Cyber Risk Terminal**：Page `#03090B`、Shell `#041013`、Panel `#06171A`、Plot `#071C20`、Sub Card `#082126`；Cyber Cyan `#27D7E5` 负责交互，Brand Green `#38D996` 只负责品牌、在线、低风险与正向结果，Blue `#3C91F2` 负责普通辅助数据，Amber `#F1B94B` 与 Coral `#FF6259` 负责中高风险，Violet `#9A7AF5` 负责 AI 通道。
2. **顶部由单行控制台改为两行**：上行 Global Header（52–56px，产品名 / Search / LIVE / Notification / AI / User），下行 Filter Toolbar（42–44px，报告年 / 行业 / 风险范围 / 样本范围 / 模型版本 / 质量提醒 / 导出 / 生成洞察）。FR-01 "单行控制台"不再适用，验收改为"两行均不换行、不裁切"。
3. **中央主视觉由"风险星图（scatter + three.js 3D）"改为 Hexbin**：使用 ECharts Custom Series Canvas 实现 2D 六边形分箱，X=ESGSI、Y=EASS；3D 模式指视角倾斜，three.js 不再作为必要技术。FR-04 中"漂绿风险星图"统一改称"风险分布 Hexbin"。
4. **底部三栏重构**：`十年趋势(28%) | 行业热力+红旗统计(36%，合并为单一 SectorRiskPanel) | EAA-ESI 瀑布图(36%，新增)`。FR-05 中"红旗与数据质量保持三栏同行"改为"红旗统计并入行业热力 Panel 右侧 28% 子区，质量数字进入该子区"。
5. **风险色全局统一**：High `#FF6259` / Medium `#F1B94B` / Low `#35CBA6` / Missing `#50666B` / Selected `#27D7E5`，所有图表共用；Selected 严格使用 Cyan，与 Brand/Low Green 分离。
6. **新增 System / Data Status 底栏**（22–26px）：`● 数据更新：YYYY-MM-DD HH:mm · 数据来源：Holographic Evidence Observatory`，替代浮动的 global-demo-notice。
7. **字体**：中文 HarmonyOS Sans SC / Source Han Sans SC，数字 Inter，技术标签 JetBrains Mono；所有数值 `font-variant-numeric: tabular-nums`。
8. **禁止效果**：大面积 Neon Glow、每 Panel 默认 Cyan 发光、高频扫描线、不断闪烁文字、RGB 彩虹渐变、玻璃拟态、强 Blur、全页粒子背景、three.js 背景球体、过大圆角（panel 8px）。
9. **响应式保留**：1440×900 与 1280×800 仍为发布阻断视口，禁止纵向滚动；1280 时 sidebar 80→68px、KPI 数字 38→30px，但三列结构不变。

## 1. 产品目标

Dashboard 面向 ESG 研究员和合规分析师，单一任务是：

> 在一个桌面视口内完成样本状态确认、风险扫描、重点公司定位，并进入证据复核。

风险只代表待复核研究信号，不构成对企业漂绿的确定性判断。正式本地运行读取后端规范化数据；自动化验收通过显式 `mock` 模式继续使用确定性合成内容。真实文档正文、私有链接和原始数据集不得进入前端或代码仓库。

## 3. 功能需求

### FR-01 单行控制台

顶部只有一个 Dashboard 控制行，顺序为：

```text
英文观测站标识 | 报告年 | 行业 | 风险 | 样本口径
| 数据契约 | 数据状态 | 导出快照 | 唤醒绿镜
```

验收：

- `1280px` 及以上不得换行。
- 所有控件完整显示，不允许裁切文字或只保留不可识别图标。
- 所有交互控件有可访问名称和可见键盘焦点。

### FR-02 连续单屏布局

页面固定为四个连续信息层，不允许插入空白 Spacer：

```text
┌──────────────────────────────────────────────┐
│ 单行控制台                                   │
├──────────────────────────────────────────────┤
│ 五项核心 KPI                                 │
├────────────┬───────────────────┬─────────────┤
│ 三方面指标 │ 风险星图          │ 高风险公司  │
├────────────┴───────────────────┴─────────────┤
│ 十年趋势       │ 行业热力      │ 红旗与质量  │
└──────────────────────────────────────────────┘
```

验收：

- KPI 与主分析区之间间距不超过 12px。
- 主分析区与底部分析区之间间距不超过 12px。
- `1280×800`、`1440×900`：无纵向滚动、无模块裁切。
- `1920×1080`、`2048×1227`：主分析区高度设上限，禁止因 `1fr` 无限拉伸产生巨型空白卡片或中部空洞。
- Desktop 主分析区高度为 320–430px；底部分析区高度至少 240px。
- 大屏剩余空间只能出现在全部模块之后，不得出现在 KPI 与主分析区之间。

### FR-03 KPI

- 首页保留五项核心 KPI：当前样本、高风险、三年持续高风险、EAA-ESI 中位数、质量提醒。
- “尚未关联证据”“证据解析失败”“已关联但覆盖率不足”保留为数据质量诊断指标，不占用首页核心 KPI 区域。
- “已关联但覆盖率不足”表示已有证据，但有效覆盖率低于 70%。三类状态必须互斥，不得重复计数。
- 默认态不显示解释性小字。
- 每项可点击打开定义、口径、当前筛选和趋势详情。
- KPI 数字不得因视口变宽而缩小。

### FR-04 主分析模块

- 左：三方面构造指标，并在同一位置切换主分析、GSI 稳健性和 Red flag 稳健性。
- 中：漂绿风险星图，作为页面唯一视觉签名。
- 右：持续高风险公司。
- 三栏顶部和底部对齐。
- 内容不足时模块保持结构，但不得用大面积无信息留白模拟“高级感”。
- 星图列宽不得超过主分析区三列有效宽度的 46%，左右研究摘要列获得更均衡的扫描空间。
- 三方面构造指标紧凑态显示：指标代码、样本中位数、关注率、较上年变化、有效样本量和跨年趋势。
- 三方面构造指标完整视图额外显示：业务描述、中间 50% 区间和趋势覆盖年份。
- 默认进入 `EAS / EAA-ESI` 主分析；切换不会离开 Dashboard，也不会创建 GSI 独立路由。
- GSI 视图显示 GSI、覆盖不足惩罚与披露失衡；Red flag 视图显示语言差距、行动实质、模糊与验证三类触发率。

### FR-05 底部模块

- 十年风险趋势、行业风险热力、红旗与数据质量保持三栏同行。
- 十年趋势与指标体系联动；主分析和 GSI 至少同时绘制中位数与平均数，Red flag 绘制三类年度触发率。
- 行业热力必须使用明亮可辨的五级色带。
- 图表坐标、图例和模块文字正常态不低于 12px。
- 红旗条、质量数字和标签不得相互挤压或截断。

### FR-06 详情与完整视图

- KPI 点击打开 KPI 详情。
- 六个非 KPI 模块统一显示右上角完整视图按钮。
- 完整视图必须重新计算图表尺寸，禁止截图放大。
- `Esc` 或关闭按钮关闭后，焦点回到原触发按钮。

### FR-07 GreenLens Copilot

- 顶部“唤醒绿镜”或 `Ctrl/Cmd + J` 打开。
- 桌面端抽屉约占视口宽度的三分之一，并以 `480px` / `720px` 作为最小与最大可读边界；移动端保持全屏。
- 保留公司、年度、指标、风险与证据上下文。
- 输出包含结论、指标影响、证据引用、不确定性和下一步复核动作。
- AI 使用紫色通道，不与风险或环境主题绿色混用。

## 4. 视觉规范

### 4.1 色彩

| 角色 | Token |
| --- | --- |
| 页面近黑青 | `#03090B` |
| Shell 黑青 | `#041013` |
| 面板深青 | `#06171A` |
| Plot 深蓝青 | `#071C20` |
| 交互 Cyan | `#27D7E5` |
| GreenLens 品牌绿 | `#38D996` |
| 普通数据蓝 | `#3C91F2` |
| 中风险琥珀 | `#F1B94B` |
| 高风险珊瑚 | `#FF6259` |
| AI 紫色 | `#9A7AF5` |

页面不使用大面积绿色背景。普通 Panel 边界使用中性青灰；Cyan 仅用于 Hover、Focus、Selected、Expand、Active 与主图边界；绿色仅用于品牌、在线、低风险和正向业务结果。

### 4.2 字体

- 中文正文：`Noto Sans SC Variable`。
- 英文观测站标识：`Space Grotesk Variable`。
- 数字与契约：`IBM Plex Mono`。
- 最小可见文字：12px。
- 筛选/正文：13–14px。
- 模块标题：17–18px。
- KPI：36–40px。

### 4.3 动效

- 首屏入场总时长不超过 500ms。
- 不允许因 stagger 延迟形成“页面加载后仍大面积空白”的观感。
- 环境光极弱；不增加漂浮粒子、装饰球或无业务意义 HUD。

## 5. 非功能需求

- Repository、Zod 数据契约和现有业务路由不得因视觉重构回退。
- 生产构建、Lint、TypeScript、Unit Test 和 Playwright 全部通过。
- Axe serious/critical 为 0。
- 页面 Console 无错误。
- ECharts Canvas 非空。
- 3D 不可用、低内存或 reduced motion 时保留完整 2D 工作流。

## 6. 发布验收矩阵

| 视口 | 必须满足 |
| --- | --- |
| `1280×800` | 单行控制台、全部模块完整、无滚动、无裁切 |
| `1440×900` | 单行控制台、主分析信息密度均衡、底部三栏完整 |
| `1920×1080` | 模块连续排列，主分析区不无限拉伸 |
| `2048×1227` | KPI 后立即出现主分析区，不得重现中部巨幅空白 |

发布阻断：

- 顶部字段换行或裁切。
- KPI 与主分析区之间出现超过 12px 的非业务空白。
- 任一模块超出视口或必须滚动才能看到。
- 主分析区高于 430px、底部分析区低于 240px，或星图列占三列有效宽度超过 46%。
- 三方面指标卡片存在可用于展示研究口径却仍为空白的区域。
- 正常态可见文字小于 12px。
- 热力图在默认亮度下无法辨认色阶。
- serious/critical 无障碍错误。
