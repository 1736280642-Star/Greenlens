# Dashboard Command Center 五阶段开发计划

> 状态：五个阶段已全部完成（2026-07-29）
> 质量门：typecheck、lint、28 项 unit、25 项 Playwright/axe、production build 全部通过

> 视觉参考：高端黑玻璃 AI SaaS + 高密度科研观测仪器
> 产品背景：中国上市公司 ESG 披露漂绿信号研究
> 核心边界：全量合成数据；风险仅为待复核信号；页面只通过 Repository 读取数据

## 阶段 1：数据聚合与 Command Center 壳层

### 开发范围

- 新增 `DashboardCommandCenterData` 聚合契约和 Zod Schema；
- 新增 Demo/HTTP Repository 方法；
- 从现有公司、历史、红旗与 `PanelYearSummary` 聚合 KPI、指标三分组、星图节点、持续高风险、年度趋势、行业热力与质量摘要；
- 建立 `/dashboard` 新组件目录、数据加载边界、Command Bar、12 列首屏壳层和基础视觉 Token；
- 清理 Dashboard 残留的 `CONTRACT-V1`、固定 `.66` 风险阈值和页面内聚合。

### 边界

- 不实现最终业务图表；
- 不安装 Three.js；
- 不修改其他页面的数据结构；
- 不接真实后端和真实数据。

### 开发顺序

1. 类型与 Schema；
2. Fixture 聚合器；
3. Repository/HTTP；
4. 单元测试；
5. Dashboard 数据加载与布局壳层；
6. Typecheck、lint、unit test。

### 验收效果

- Dashboard 只调用一个 Command Center 聚合接口；
- 1440px 出现完整首屏网格骨架；
- KPI 和各 Panel 均获得真实合成聚合数据；
- 空、慢、错误状态有成因、影响和下一步；
- 不再出现 v1 或固定阈值文案。

## 阶段 2：二维业务模块与联动

### 开发范围

- KPI Rail 与 Sparkline；
- 三方面指标卡；
- 近三年持续高风险 Watchlist；
- 十年趋势图；
- 行业 × 指标热力；
- 红旗结构和数据质量；
- ECharts 2D 风险矩阵作为 3D fallback；
- 指标、行业、公司之间的联动筛选。

### 边界

- 不加入 WebGL；
- 不重构绿镜内容；
- 不展示方法流程和人工任务流；
- 不虚构月度或实时数据。

### 开发顺序

1. KPI 与指标卡；
2. 2D 风险矩阵；
3. Watchlist；
4. 趋势、行业与质量；
5. 共享选择状态和 URL；
6. 组件测试与桌面截图。

### 验收效果

- 第一屏已具备完整业务可用性；
- 点击指标、行业或公司会联动所有相关 Panel；
- 近三年持续高风险来自历史数据，不由页面伪造；
- 风险与数据质量明确分离；
- 即使后续 3D 加载失败，Dashboard 仍能完整使用。

## 阶段 3：3D 漂绿风险星图

### 开发范围

- 引入 `three / @react-three/fiber / @react-three/drei`；
- InstancedMesh 公司节点；
- 风险内核、行动缺口中环、红旗外环；
- 行业空间簇、三年风险尾迹、选中数据流；
- Hover、Click、Shift+Click、受限旋转与缩放；
- Flat Mode、WebGL 检测与低性能降级。

### 边界

- 页面只允许一个 WebGL Context；
- 3D 不承担不可精确读取的主统计结论；
- 不加入 3D 地球；
- 不引入 GSAP、Pixi、D3 或 deck.gl；
- 不在 3D 场景中渲染大量文字。

### 开发顺序

1. 依赖与动态 Chunk；
2. 基础场景和坐标；
3. 实例化节点；
4. 光环与轨迹；
5. DOM Tooltip 和跨 Panel 联动；
6. Flat Mode、reduced motion、性能采样。

### 验收效果

- 高性能设备可保持 55–60 FPS；
- WebGL 不可用时自动回退 2D；
- 3D 与 Flat Mode 选择结果一致；
- 选中公司可定位到 Watchlist、证据和对比；
- 3D 空间增强理解，不改变指标真实数值。

## 阶段 4：绿镜 Copilot 与电影级交互

### 开发范围

- AI 证据助手重命名为 `绿镜 GreenLens Copilot`；
- Dashboard 默认隐藏，按钮或 `Ctrl/Cmd + J` 唤醒；
- 七类任务入口：报告体检、风险解释、指标解释、跨年同行、事件关联、研究卡片、数据质量；
- 固定回答结构和引用跳转；
- 1.5–1.8 秒启动编排、扫描光、节点聚合、数据流；
- Hover 景深、极弱浮动和风险波纹。

### 边界

- 不展示模型内部思考链；
- 不把风险分解释为概率；
- 不输出“确认漂绿”；
- 不让持续动画遮挡或延迟数据阅读；
- 不修改报告检测的底层模拟状态机。

### 开发顺序

1. 绿镜组件拆分；
2. 快捷键、焦点和上下文；
3. 任务入口和结构化回答；
4. 引用和复核跳转；
5. 启动动画与数据流；
6. reduced motion 和键盘测试。

### 验收效果

- Dashboard 默认无常驻 AI 侧栏；
- 打开后保留当前公司、年份、指标和证据上下文；
- 每个回答包含证据、不确定性与下一步；
- 开关、关闭、跳转和焦点恢复完整；
- 动画具有仪式感但不阻塞操作。

## 阶段 5：响应式、性能、可访问性与交付

### 开发范围

- 1440×900、1280×800、768×1024、390×844 响应式；
- 低性能和 reduced-motion 模式；
- 图表数据表、键盘选择、颜色之外的状态表达；
- Loading、Empty、Error、Slow、Unavailable；
- Unit、lint、typecheck、build、Playwright、axe；
- 截图、性能记录、数据字典和复盘更新。

### 边界

- 移动端不复刻完整 3D 研究工作台；
- 不为通过截图而隐藏核心功能；
- 不删除现有跨页面工作流；
- 不引入真实企业或隐私数据。

### 开发顺序

1. Desktop 密度和 Panel 尺寸；
2. Tablet/Mobile 减法布局；
3. 可访问性与键盘；
4. 性能与降级；
5. 自动化测试；
6. 截图巡检与复盘。

### 验收效果

- 四个目标视口无横向溢出、重叠或空 Canvas；
- 关键页面严重可访问性问题为 0；
- 3D 失败不影响核心调查；
- 全部质量门通过；
- 演示者可完成“筛选 → 选公司 → 解释 → 证据 → 复核”的完整路径。
